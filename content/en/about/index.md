{{% blocks/section %}}
LEIKAH is a collection of technical documentation for the offensive security techniques I have accumulated through training courses, certifications, and independent study and research.
This website is **NOT**  a source of learning in of itself, but you are at the right place if you are looking for a cheatsheet for CTF challenges, certification exams or an actual offensive security engagement.

LEIKAH is an ongoing open-source project that will take some time to complete. If you would like to contribute, check out this website's [project repo](https://github.com/RandomChugokujin/leikah).
