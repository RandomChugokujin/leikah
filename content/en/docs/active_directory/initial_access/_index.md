title: Initial Access
description: What do I have to do to get my first set of domain credentials?
categories: [Active Directory]
tags: [Active Directory, Initial Access]
weight: 2
---

For broad, authenticated enumeration of an Active Directory domain, we generally need usable domain credentials. SYSTEM access on a domain-joined computer can also allow us to authenticate using that computer's domain account. Some initial information can be gathered without credentials, as described in the initial enumeration article. If we are not given any domain credentials for the engagement, we will have to find a way to obtain authenticated access.
